# Direção Visual — Cérebro Autoral

## Origem

Esta direção foi derivada das imagens de referência fornecidas pelo proprietário do produto em 16/09/2026. As imagens foram tratadas como referência de linguagem visual e experiência, não como especificação literal de dados ou arquitetura.

## Princípios visuais

1. Sensação de acervo pessoal, reflexão, confiança e profundidade.
2. Azul-marinho profundo como base institucional.
3. Azul luminoso para ações primárias, navegação ativa e foco.
4. Fundos claros azulados, cartões brancos e bordas discretas.
5. Títulos serifados para reforçar caráter editorial e autoral.
6. Texto de interface em fonte sem serifa para legibilidade.
7. Cartões arredondados, sombra leve e bastante espaço em branco.
8. Estados semânticos consistentes: verde para concluído/validado, âmbar para revisão/atenção, violeta para incorporação/influência, vermelho para risco/erro.
9. Interface mobile-first, com navegação inferior no celular e sidebar no desktop.
10. O conteúdo deve parecer mais importante que a tecnologia.

## Adaptação ao novo produto

As referências usam a marca histórica “Memória Reflexiva”. A implementação nova usa **Cérebro Autoral** e segue a arquitetura canônica atual.

A interface não deve mostrar números ou análises fictícias. Enquanto o corpus estiver vazio, a UI deve comunicar estado inicial, próximos passos e ausência de evidências.

## Navegação principal

- Início
- Biblioteca
- Meu Cérebro Autoral
- Reflexões
- Configurações

A ação “Nova reflexão” permanece destacada no cabeçalho. No celular, a navegação principal usa barra inferior e a ação de nova reflexão permanece acessível no topo.

## Telas de referência incorporadas ao sistema

- Login
- Início / dashboard
- Biblioteca
- Adicionar conteúdo
- Detalhe do documento — será implementado quando a entidade documental estiver disponível
- Meu Cérebro Autoral
- Criar reflexão
- Minhas Reflexões
- Configurações

## Regra de produto

A estética não pode simplificar ou distorcer a arquitetura intelectual. Conceitos como autoria, proveniência, evidência, versão, revisão e influência externa deliberada devem permanecer visíveis quando forem relevantes à decisão do usuário.
