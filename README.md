# Cérebro Autoral

Plataforma de Inteligência Autoral Personalizada.

## Objetivo

Transformar produção intelectual em conhecimento estruturado, inferir metodologia autoral com evidências e proveniência, construir um Cérebro Autoral versionado e utilizá-lo para apoiar a criação de novas reflexões personalizadas com revisão humana.

## Princípios

- pesquisar antes de supor;
- validar antes de persistir;
- testar antes de publicar;
- versionar antes de substituir;
- preservar a proveniência;
- proteger a autoria;
- manter o Cérebro Autoral como centro da arquitetura.

## Stack inicial

- Next.js + React + TypeScript
- Supabase PostgreSQL + Auth + Storage + pgvector
- OpenAI API
- Vercel
- GitHub
